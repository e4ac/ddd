# DDD
A Rust library for Domain-Driven Design.

## Mandatory Quality Gates
- Ensure all unit tests pass by running `cargo test --all-features --all-targets`
- Ensure code formatting is correct by running `cargo fmt --all -- --check`
- Ensure the code style is correct by running `cargo clippy --all-features --all-targets -- -D warnings`
- Must resolve every issue and warning before continuing

## Unit Tests
All unit tests follow the Arrange-Act-Assert pattern. Ensure tests cover all edge cases when generating unit tests.
